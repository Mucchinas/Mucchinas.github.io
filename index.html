    A comprehensive, solo-developed multi-tenant ERP/SaaS platform for inventory management, architected from the ground up. This project covers the full end-to-end software lifecycle.

    • Backend: Architected a multi-tenant schema-per-tenant system in Spring Boot (handling JWT-based datasource routing) and a Flask microservice for automated tenant provisioning and backups.
    • Data Layer: Utilized a hybrid data strategy, integrating PostgreSQL (main relational data), Redis for high-speed caching, and Neo4j to map complex inventory and supply chain relationships.
    • Frontend: Developed a responsive administrative dashboard using React.
    • DevOps & Monitoring: Containerized all services (Docker) and configured NGINX as the reverse proxy. Implemented a full observability stack using Prometheus for metrics and Grafana for visualization.
    • Features: Integrated MinIO (S3-like) for document storage, Authentik for OIDC/SSO, and n8n for workflow automation (AI Assistant).
